Smart Event Planning Platform with Resource Coordination System

A Django-based backend platform for efficient event planning and resource coordination.

Current Features
Event creation, updating, viewing, and deletion.
Budget and expense tracking with automatic budget alerts.
Resource management, allocation, and conflict detection.
Attendee registration with capacity and validation checks.
Vendor and sponsor management.
Approval workflow and automated notifications.
Event dashboard with key event statistics.
REST-style APIs tested using Thunder Client.
